Office PDF 工具

当前文档 → PDF

使用 Office 原生导出，保留字体与排版，无需上传。

本地文件 → PDF

支持 Word / Excel / PowerPoint / ODF / RTF / TXT / CSV / HTML 等，由服务端引擎批量转换。

点击选择文件，或把文件拖到这里
高级选项

PDF → Office / 图片

文本模式尽量还原可编辑内容；图片模式逐页渲染，版式 100% 保真。

点击选择 PDF，或拖拽到这里

图片 → PDF

支持 PNG / JPG / WebP / GIF / BMP / TIFF，可调整顺序、页面尺寸与每页张数。

点击选择图片，或拖拽到这里

PDF → 图片

按页渲染为图片，可指定页码范围与分辨率，多页自动打包 ZIP。

点击选择 PDF，或拖拽到这里

合并文档

合并同类型文件：PDF 直接拼页；Word 追加正文；Excel 汇总工作表；PowerPoint 追加幻灯片。

点击选择多个同类型文件，或拖拽到这里

拆分文档

PDF 按页；Word 按标题或分节符；Excel 按工作表或行数；PowerPoint 按幻灯片。

点击选择要拆分的文件，或拖拽到这里
